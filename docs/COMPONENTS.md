# Rice components

This is a Cinnamon rice, so it uses Cinnamon's own parts instead of installing
a second window manager or desktop.

| Part | What this rice uses |
| --- | --- |
| Window manager and compositor | Cinnamon + Muffin |
| Panel and status area | Cinnamon panel + custom red status applet |
| App launcher and power menu | Rofi |
| Terminal | Ghostty |
| Shell and prompt | Bash + Starship |
| Notifications, lock, idle and OSD | Cinnamon |
| Wallpaper | Cinnamon background setting; bring your own image |
| GTK 2/3/4 and window borders | Hacker Red + Orchis Red Dark |
| Icons and cursor | Hacker Red Universal + Oreo Spark Red |
| File manager | Nemo |
| Desktop dashboard | Supervised Conky monitor + GTK widgets |
| CLI tools | Neofetch, btop, CAVA, eza, bat and fzf helpers |
| Music | Cinnamon music widget + MPD/MPC |
| Screenshots | gnome-screenshot helper |
| Clipboard and color picker | Rofi/xclip + Zenity helpers |
| Workspaces and window effects | Cinnamon settings |
| Dock | Plank |

Firefox, Chromium, the login screen, GRUB and Plymouth are intentionally not
changed. Qt styling is also left alone because the matching user-only Qt theme
tools are not part of a normal Mint Cinnamon install.
