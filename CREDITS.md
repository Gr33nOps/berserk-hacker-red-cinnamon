# Credits

Berserk Hacker Red is possible because desktop theming is a long chain of
design, maintenance, and community work.

## Theme foundations

- **dstakaroot** created Cinnamon Hacker and the Dedicated-to-Hackerer concept
  that inspired this project. Cinnamon Hacker itself credits **Tyr-jord** for
  baseline graphic work.
- **vinceliuice and Orchis contributors** created the window-decoration base,
  building on **nana-4's Materia** project.
- **varlesh and Oreo cursor contributors**, including **Sourav Goswami**,
  created the Oreo Spark Red cursor set.

## Cinnamon ecosystem

- **fredcw** maintains Cinnamenu; **Jason Hicks (`jaszhix`)** authored the
  earlier implementation. Its bundled `CREDITS` records the wider lineage,
  code contributors, artists, search providers, and translators.
- The **Linux Mint and Cinnamon teams** build the desktop, Nemo, applet system,
  settings stack, and theming platform this project integrates.

## Tools and integrations

Thanks to the maintainers of Cinnamon, Nemo, Conky, Rofi, Ghostty, Starship,
CAVA, btop, Plank, MPD/MPC, Hidamari, Pillow, gnome-screenshot, xclip, Zenity,
eza, bat, fzf, xdotool, wmctrl, Inter, and JetBrains Mono Nerd Font.
MPRIS-compatible players are read through the desktop message bus. ZenQuotes
provides the optional online quote source.

The terminal's Unicode Braille-style Brand emblem was supplied by the project
user through [Emoji Combos' Dot Art Editor](https://emojicombos.com/dot-art-editor).
Its 15 artwork rows are preserved exactly; only Neofetch's invisible color
markup is added before the first row.

Exact redistribution status, licenses, source links, and local modifications
are documented in [THIRD_PARTY.md](THIRD_PARTY.md).
